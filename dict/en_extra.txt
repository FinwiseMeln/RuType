# en_extra: тех-токены, аббревиатуры и бренды, которых нет в en_US Hunspell.
# Расширяет IsValidEn и потому работает в обе стороны:
#   - защита от ложной перекладки en->ru (по логу правок: tcp -> 'ест',
#     url -> 'год', ctrl -> 'секс', dir -> 'век', gui -> 'паш', cdn -> 'свет');
#   - автоперекладка ru->en, когда токен набран в русской раскладке
#     ('пшерги' -> github), без ручного правила в rules.txt.
# Регистр не важен - сверка идёт по строчной форме.
